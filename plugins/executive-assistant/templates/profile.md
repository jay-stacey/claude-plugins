# Assistant profile

The assistant reads this file at the start of the morning brief, the shutdown
and every focus session. Edit it by hand any time. `/init` can fill it in for
you.

## Workday

- Start: 06:30
- Stop: 15:00
- Deep work window: 06:30 to 11:30
- Admin and catch-up: after 13:30
- Shutdown reminder: 30 minutes before stop
- Workdays: Monday to Friday

## Recurring week

Write the fixed points of your week here, one per line, so planning can work
around them. Example:

- Monday 09:00 to 11:00: cycle planning (code freeze day)
- Wednesday 13:00: go/no-go
- Thursday evening: deploy (shutdown runs earlier)

## Focus profile

- Hard parts: starting tasks, getting back after interruptions, forgetting follow-ups, too many open threads
- Time blindness: late to meetings, tasks take longer than planned, days vanish
- What helps: body doubling, one thing at a time, novelty and streaks
- Nudges: gentle
- Peak focus: early morning, mid-morning
- Shutdown style: night work is fine when planned
- Rewards: done list, streaks, points

## People who always get through

Names or addresses whose mail is always kept, one per line. The email rules
file uses these for `<ceo-address>` and similar placeholders.
